## NAVIGATION IMPLEMENTATION

### AppNavigator.tsx

```typescript
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import { useAuthStore } from '../store/authStore';

const Stack = createNativeStackNavigator();

export default function AppNavigator() {
  const { accessToken, currentRole, isNewUser } = useAuthStore();

  return (
    <NavigationContainer>
      <Stack.Navigator screenOptions={{ headerShown: false }}>
        {!accessToken ? (
          // Not logged in → Auth flow
          <Stack.Screen name="Auth" component={AuthNavigator} />
        ) : isNewUser || !currentRole ? (
          // Logged in but no role selected
          <Stack.Screen name="RoleSelect" component={RoleSelectScreen} />
        ) : currentRole === 'seeker' ? (
          // Seeker dashboard
          <Stack.Screen name="SeekerMain" component={SeekerNavigator} />
        ) : (
          // Provider dashboard
          <Stack.Screen name="ProviderMain" component={ProviderNavigator} />
        )}
      </Stack.Navigator>
    </NavigationContainer>
  );
}
```

## SCREEN-BY-SCREEN COMPONENT SPEC

---

### SplashScreen.tsx

```
DISPLAY:
  - Full screen: background color (brand color)
  - Center: App logo (120x120)
  - Below logo: App name text
  - Bottom: Subtle animation (pulse or fade)

LOGIC:
  - Mount → check SecureStore for access_token
  - If token exists → try refresh → navigate to dashboard
  - If no token → navigate to LoginScreen
  - Duration: max 2 seconds

STATE:
  - None (stateless check)
```

---

### LoginScreen.tsx

```
DISPLAY:
  - Logo (smaller)
  - Headline: "Find Work Near You"
  - Subtext: "Join millions of local workers"
  - Country code: +91 (fixed for India)
  - Phone number input (numeric keyboard)
  - "Get OTP" button (disabled until 10 digits entered)
  - Terms of service text at bottom

LOGIC:
  - Validate: exactly 10 digits
  - Call API: POST /api/v1/auth/send-otp
  - On success: navigate to OTPScreen with phone param

VALIDATION:
  - phone.length === 10
  - phone starts with 6-9 (Indian mobile numbers)
```

---

### OTPScreen.tsx

```
DISPLAY:
  - "Enter OTP" headline
  - Sent to: "+91 9876543210"
  - 6-box OTP input (auto-advance on each digit)
  - "Verify" button
  - "Resend OTP" (disabled 60 seconds, shows countdown)
  - "Change Number" link

LOGIC:
  - Firebase OTP confirmation:
    const credential = PhoneAuthProvider.credential(verificationId, otp);
    const result = await signInWithCredential(auth, credential);
    const firebase_id_token = await result.user.getIdToken();
  - POST /api/v1/auth/verify-otp { phone, firebase_id_token }
  - Store access_token + refresh_token in SecureStore
  - If new user → RoleSelectScreen
  - If existing user → appropriate dashboard

ERROR STATES:
  - "Invalid OTP" → shake animation on boxes
  - "OTP expired" → show resend option
```

### RoleSelectScreen.tsx

```
DISPLAY:
  - "What would you like to do?" headline
  - Two large cards:
    Card 1: [Icon] "Find Work"
            "Browse nearby jobs and apply instantly"
    Card 2: [Icon] "Post a Job"
            "Hire workers for your business quickly"
  - "You can switch roles anytime" note below

LOGIC:
  - On card tap → PUT /api/v1/users/me/role { role: 'seeker'|'provider' }
  - Update authStore.currentRole
  - Navigate to correct dashboard
```

### SeekerDashboard.tsx

```
DISPLAY:
  - Header: "Good morning, [Name] 👋" + Notification bell icon
  - Search bar: "Search jobs..." → tap opens JobSearchScreen
  - Category scroll: horizontal icon list (Delivery, Restaurant, etc.)
  - Section: "Jobs Near You"
    → JobCard list (sorted by distance)
    → "See all" link
  - Section: "Recommended for You"
    → JobCard list (sorted by matching score)

JOB CARD DISPLAY:
  - Job title (bold)
  - Employer name + rating stars
  - Work type badge (Hourly/Daily/Monthly)
  - Salary (₹600/day or ₹150/hr)
  - Distance (1.4 km away)
  - "Urgent" badge (if urgent_hiring = true)
  - "Apply" button (one tap)

DATA FETCH:
  - On mount: GET /api/v1/jobs?lat=&lng=&city= (nearby)
  - On mount: GET /api/v1/jobs/recommended?lat=&lng=&city=
  - Refresh on pull-to-refresh
  - Cache results in jobsStore (60 second TTL)
```

## COMPLETE APPLICATION STATE FLOW

```
User opens app
    │
    ├── SecureStore: access_token exists?
    │       │
    │       ├── YES: try /auth/refresh-token
    │       │       │
    │       │       ├── Success: update tokens → route by current_role
    │       │       └── Failed: clear tokens → LoginScreen
    │       │
    │       └── NO: SplashScreen → LoginScreen
    │
Login + OTP
    │
    ├── Firebase OTP verify
    │       │
    │       └── Get firebase_id_token
    │
    ├── POST /api/v1/auth/verify-otp
    │       │
    │       ├── is_new_user: true → RoleSelectScreen
    │       └── is_new_user: false → route by current_role
    │
Role Selected
    │
    ├── current_role = 'seeker' → SeekerNavigator
    └── current_role = 'provider' → ProviderNavigator

Role Switch (anytime from Profile)
    │
    ├── PUT /api/v1/users/me/role
    ├── Update authStore.currentRole
    └── Reset navigation to new dashboard
        (React Navigation: navigation.reset())
```
