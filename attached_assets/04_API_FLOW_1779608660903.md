### POST /api/v1/auth/verify-otp
```json
REQUEST:
{
  "phone": "9876543210",
  "firebase_id_token": "eyJhbGc..."   ← From Firebase SDK after OTP verify
}

FLOW:
1. Backend calls Firebase Admin: admin.auth().verifyIdToken(firebase_id_token)
2. Confirms phone matches
3. Creates or fetches user in PostgreSQL
4. Generates access_token (JWT, 15min) + refresh_token (30 days)
5. Stores refresh_token hash in DB
6. Returns user + tokens

RESPONSE 200:
{
  "success": true,
  "data": {
    "access_token": "eyJhbGc...",
    "refresh_token": "eyJhbGc...",
    "is_new_user": true,
    "user": {
      "id": "uuid",
      "phone": "9876543210",
      "name": null,
      "city": null,
      "current_role": "seeker",
      "is_phone_verified": true,
      "trust_score": 0.00
    }
  }
}
```

### GET /api/v1/jobs
**Purpose:** Nearby job feed (seeker dashboard)
**Requires JWT**
```
QUERY PARAMS:
  lat         REQUIRED  User latitude
  lng         REQUIRED  User longitude
  city        REQUIRED  User city
  radius      OPTIONAL  Distance in km (default: 10)
  category_id OPTIONAL  Filter by category
  work_type   OPTIONAL  hourly | daily | monthly
  page        OPTIONAL  (default: 1)
  limit       OPTIONAL  (default: 20)

BACKEND FLOW:
1. Filter by city (fast SQL: WHERE city = :city AND status = 'active')
2. Apply category filter if provided
3. Apply work_type filter if provided
4. Calculate Haversine distance for remaining records
5. Filter by radius
6. Sort by: distance ASC, created_at DESC
7. Return paginated results

RESPONSE 200:
{
  "success": true,
  "data": {
    "jobs": [
      {
        "id": "uuid",
        "title": "Delivery Boy Needed",
        "category": { "id": 1, "name": "Delivery", "icon_name": "bicycle" },
        "work_type": "daily",
        "daily_wage": 600,
        "city": "Hyderabad",
        "distance_km": 1.4,
        "is_urgent": true,
        "food_included": false,
        "accommodation_included": false,
        "provider": {
          "id": "uuid",
          "name": "Ravi Shop",
          "avg_rating": 4.2,
          "total_ratings": 18,
          "is_verified": true
        },
        "created_at": "2024-01-15T10:30:00Z"
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 20,
      "total": 85,
      "has_more": true
    }
  }
}
```

### GET /api/v1/jobs/search
**Purpose:** Full text search
**Requires JWT**
```
QUERY PARAMS:
  q           REQUIRED  Search keyword
  city        REQUIRED  City filter
  lat         OPTIONAL  For distance sort
  lng         OPTIONAL  For distance sort
  page        OPTIONAL

BACKEND FLOW:
1. Build tsquery from q param
2. WHERE city = :city AND status = 'active'
3. AND search_vector @@ to_tsquery('english', :q)
4. ORDER BY ts_rank(search_vector, query) DESC
5. Return results with rank score

RESPONSE 200:
{
  "success": true,
  "data": {
    "jobs": [...],
    "query": "delivery",
    "total": 12
  }
}
```

### POST /api/v1/jobs
**Purpose:** Post a new job
**Requires JWT + Provider role**
```json
REQUEST (hourly example):
{
  "title": "Waiter Needed for Event",
  "category_id": 8,
  "description": "Need 2 waiters for Saturday evening event",
  "work_type": "hourly",
  "hourly_rate": 150,
  "total_hours": 6,
  "shift_start_time": "18:00",
  "shift_end_time": "00:00",
  "same_day_payment": true,
  "urgent_hiring": true,
  "city": "Hyderabad",
  "address": "Banjara Hills, Hyderabad",
  "latitude": 17.4156,
  "longitude": 78.4347,
  "skills_required": [3, 7]   ← skill IDs
}

BACKEND FLOW:
1. Validate JWT → get provider_id
2. Validate request body
3. Run scam detection algorithm → calculate scam_score
4. If scam_score >= 0.90 → reject with error
5. If scam_score >= 0.70 → save with status='pending_review'
6. If scam_score < 0.70  → save with status='active'
7. Insert job record
8. Insert job_skills records
9. search_vector auto-built by trigger
10. Set expires_at = NOW() + 7 days
11. Queue notification: push to nearby matching workers (async)

RESPONSE 201:
{
  "success": true,
  "data": {
    "id": "uuid",
    "status": "active",
    "scam_score": 0.0,
    "expires_at": "2024-01-22T10:30:00Z"
  }
}
```

## MATCHING ROUTE
## ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### GET /api/v1/jobs/recommended
**Purpose:** Weighted algorithm job recommendations for seeker
**Requires JWT + Seeker role**
```json
QUERY:
  lat     REQUIRED
  lng     REQUIRED
  city    REQUIRED

BACKEND FLOW:
1. Get seeker's skills and preferences from DB
2. Filter jobs: WHERE city = :city AND status = 'active'
3. Filter by preferred categories if set
4. Calculate matching_score for each:
   - skill_match_score (0.0 to 1.0) × 0.40
   - location_score (inverse of distance) × 0.30
   - salary_match_score × 0.20
   - availability_score × 0.10
5. Sort by matching_score DESC
6. Return top 20

RESPONSE 200:
{
  "success": true,
```
